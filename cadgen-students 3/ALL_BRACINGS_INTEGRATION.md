# Восемь креплений в восстановлении декомпозированной модели

## Существующий процесс

`assembly_source.generate_source` создаёт исходник CADGen и историю операций.
`decomposition.decompose_geometry` выделяет геометрические компоненты без учёта
креплений. Этот алгоритм не изменён.

`decomposition_assembly.assemble_partition` находит контактирующие пары через
`contact_patch`, строит локальную систему координат контактной поверхности и
вызывает `joint_design.propose_joints`. Прежние пазы создавались в
`legacy_joints`/`propose_adaptive_joints` через `assembly_geometry.build_groove`.
`make_joint` переводит добавляемые и удаляемые объёмы в координаты исходника.
`materialize` применяет их к исходным компонентам, добавляя отдельный крепёж
только там, где это предусмотрено типом соединения.

Новый `assembly_connections.propose_all_connections` расширяет именно этот
подбор, а не генерирует независимые демонстрационные пары.

## Выбор креплений

Режим `all` рассматривает восемь типов:

| Тип | Используемая реализация |
|---|---|
| mortise_tenon | build_groove с rectangular, прежний адаптивный подбор |
| tongue_groove_stop | build_tongue_groove_stop |
| dovetail | build_groove с dovetail, прежний адаптивный подбор |
| pinned | build_pin, отдельный штифт |
| bolted | существующие bolt_group / build_bolted, болт и гайка |
| bayonet | build_bayonet, включая локальную проверку вставки и поворота |
| threaded | build_threaded, интегральный цилиндрический выступ и гнездо |
| snap_fit | build_snap_fit, включая локальные деформированные состояния |

Для пазов и болтов сначала применяется прежний простой подбор, затем при
отказе — существующий адаптивный. Для остальных соединений проверяются
разные роли деталей; для размерных вариантов используются параметры готовых
построителей. Детали не масштабируются. Все варианты проходят реальные
проверки построителя и `validate_connection`. Непоместившиеся варианты
отклоняются с причинами; round и v не рассматриваются.

`preferred_types` — порядок предпочтений среди допустимых вариантов,
а не требование создать невозможное крепление. При поиске связного набора
соединений сначала рассматриваются ещё не использованные допустимые типы.
Пересекающиеся защитные области креплений не допускаются. Поиск ограничен
бюджетами и не гарантирует нахождение всех возможных решений.

## Геометрия отдельно от порядка установки

`assemble_partition(..., check_sequence=False)` и
`validate_partition(..., check_sequence=False)` проверяют:

- сохранение исходных геометрических компонентов;
- валидность тел, отсутствие недопустимых общих пересечений;
- изменение материала только в объявленных областях креплений;
- сохранение геометрии каждого соединения в его защищённой области;
- фактическое положение дополнительных компонентов;
- связность графа соединений.

Локальные проверки сохраняются в `parameters.local_geometry_checks`.
Проверки bayonet и snap_fit не отключаются. Ограничение их прежних
планировщиков «только изолированная пара» не применяется, поскольку в этом
режиме глобальный `find_sequence` вообще не вызывается.

Успех обозначается `geometry_verified`. Последовательность пуста,
`assembly_sequence_checked=false`, `assembly_sequence_status="not_requested"`.
Это не доказательство физической собираемости всей конструкции: локально
допустимые движения могут конфликтовать с третьими деталями.

`generate_auto_batch` по умолчанию использует геометрический режим;
его `auto` рассматривает все восемь типов. CLI:

```text
python -m cadgen.assembly_generator --decomposition auto --connection all --count 10
```

Старый ограниченный поиск последовательности сохранён: явный
`check_sequence=True` или CLI `--check-sequence`. Прямой вызов
`assemble_partition` сохраняет прежнее значение по умолчанию для совместимости.

## Серия проверки

`validate_all_bracings.py OUTPUT` запускает ровно десять CADGen-исходников
с фиксированными seed через `generate_auto_batch`, без подмены исходников
изолированными парами. Для каждой модели используется одна попытка;
неудачи сохраняются в manifest/summary, а не заменяются скрытыми повторами.
Генератор сохраняет исходные STEP/STL и параметры до попытки декомпозиции.
После декомпозиции сохраняются geometry, assembly_report и, при успехе,
восстановленная сборка, отдельные детали, разнесённые виды и metadata.

Результаты следует помещать в `generations/assemblies/`: эта директория уже
исключена из Git. Новые запуски требуют новой директории.

Геометрическая совместимость не подтверждает прочность, материал защёлки,
фактическое резьбовое удержание, глобальный порядок установки или непрерывные
траектории. Полноценный планировщик на этом этапе не реализован.
