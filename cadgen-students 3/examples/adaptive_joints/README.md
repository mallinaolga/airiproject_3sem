# AIRI: адаптивные соединения десяти моделей

Готовые результаты `adaptive_joints_final`: 86 основных деталей после креплений, 76 установленных пазовых соединений. Новая генерация и изменение алгоритма не выполнялись.

**Часть соединений микроскопическая.** Геометрическая проверка не подтверждает изготовимость или прочность. [Аудит всех 76 размеров и причин выбора](../../JOINT_DIMENSIONS.md). Пути проверены дискретно, непрерывная бесстолкновительность не доказана.
