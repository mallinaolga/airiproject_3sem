# AIRI: итоговый эксперимент автоматической декомпозиции

Ветка: `assembly-generation`. База: `27ff3e38a89b34312f60bf8e8f488eb19f052432`.
Коммит и push этой доработки не выполнялись.

## Полный запуск

Из `cadgen-students 3`, с зависимостями проекта:

```bash
python -m cadgen.assembly_generator --count 10 --decomposition auto --connection auto --seed 42 --max-attempts 16 --output generations/assemblies/auto_seed42_final --examples examples/assemblies
python -m unittest discover -s test -p 'test_*.py' -v
python test/validate_auto_examples.py --folder examples/assemblies
```

Каталоги в команде уже существуют после выполненного эксперимента. Для повторения
выберите новые выходные каталоги; существующие результаты защищены от перезаписи.
Фактические seed отдельных моделей находятся в README примеров и metadata.

**Все десять моделей в этой серии используют пазовые соединения. Болтов и
комбинированных соединений в демонстрационной серии нет.** Выбор не подменялся
ради разнообразия. Автоматические болтовые и комбинированные конструкции,
несколько болтов, совместное размещение крепежа и полный порядок сборки
проверены отдельно на контрольной CAD-геометрии. В частности, длинная
направляющая с доступным отдельным каналом выбирает комбинированный вариант;
широкий плоский стык выбирает несколько болтов.

## Статистика и проверки

- Получено **10/10** успешных сборок из **21** исходника.
- Отклонено **11** исходников: 9 не прошли проверку одного валидного Solid;
  2 не дали выполнимой целесообразной декомпозиции в рамках поиска.
- Финальный запуск занял **378.457 с**, включая отказы, проверки и экспорт.
  Это наблюдение одного прогона, не бенчмарк.
- **44 теста прошли**: 24 прежних и 20 новых. Дополнительно повторно проверен
  полный порядок установки комбинированного соединения после усиления теста.
- Независимый валидатор прочитал все сохранённые модели и представления.
  Для каждого исходника исполнен его `original.py`: результат совпадает с
  `original.step`. Все 10 исходников геометрически различны.
- Проверены отдельные Solid, восстановление исходника из частей до креплений,
  конечные положения, все пары на пересечения, связный реальный граф стыков,
  состав и порядок сборки, разобранные положения и ссылки README.
- По параметрам креплений заново построены ожидаемые компоненты и пустоты.
  Пространственное сравнение B-Rep с экспортом прошло в CAD-допуске.
  Максимальная ошибка геометрии технологических пустот:
  **0.0 мм³**.
- Разность отдельных численно интегрированных значений объёма после импорта
  записана отдельно в `validation.json`; она не заменяет прямую проверку
  симметрической разности геометрических множеств.
- В каталоге примеров **279 файлов**, около **19.66 MB**.
  Наибольший STL — **193684 байт**,
  все подходят под установленный предел 10 MB для GitHub.

## Реализация и границы применимости

Алгоритм, формула оценки, критерии остановки, правила креплений и поиск порядка
подробно описаны в [AUTO_DECOMPOSITION.md](AUTO_DECOMPOSITION.md).

Полностью реализованы и проверены: автоматический анализ B-Rep-сечений,
рекурсивное разбиение с переменным числом частей, сохранение исходной геометрии,
реальный граф стыков, все шесть профилей, автоматическое ранжирование пазовых,
болтовых и комбинированных вариантов, контроль защищённых зон и нескольких
креплений, проверенный по отсчётам полный порядок, четыре представления,
отдельные компоненты STEP и повторный импорт, воспроизводимость seed,
отчёт об отказах и сохранение двухкомпонентного режима.

Эвристическими/ограниченными остаются: поиск трёх доминирующих семейств плоскостей,
оценка простоты числом граней, жадный выбор разрезов с ограниченной заменой
родительских креплений, локальная оценка материала и консервативный поиск
полной сквозной колонны под болт. В этой серии последний критерий привёл
к предпочтению пазов; разнообразие болтовых схем на произвольных CADGen-моделях
ещё требует расширения поиска площадок. Глобальная оптимальность, глобальная
минимальная толщина, произвольные криволинейные движения и непрерывная
бесстолкновительность не доказаны. Резьба, механическое удержание и прочность
не моделируются.

## Файлы

Изменены:

- `cadgen/assembly_source.py`: отдельная более сложная конфигурация для auto,
  прежняя генерация по умолчанию сохранена;
- `cadgen/assembly_geometry.py`: точные контактные площадки и необязательные
  ограничения размеров/позиций для старых построителей;
- `cadgen/assembly_generator.py`: переключение CLI и параметры нового режима;
- `README.md`, `ASSEMBLY_GENERATION.md`: ссылки на новый режим.

Созданы:

- `cadgen/decomposition.py` — анализ, оценки, рекурсия и причины остановки;
- `cadgen/joint_design.py` — геометрическое ранжирование и сборка креплений;
- `cadgen/assembly_planning.py` — граф, общая проверка и порядок сборки;
- `cadgen/auto_assembly.py` — серия, экспорт и подготовка примеров;
- `test/test_auto_decomposition.py`, `test/validate_auto_examples.py`;
- `AUTO_DECOMPOSITION.md`, этот `AUTO_EXPERIMENT.md`;
- `examples/assemblies/README.md`, `experiment.json`, `validation.json`,
  ровно десять каталогов `model_01`–`model_10` с необходимыми файлами.

Ядро CADGen, исходные определения профилей, Bolty/Gaiki/Otverstiya и их прежние
тесты не изменены. Предварительные/массовые результаты оставлены только
в исключённом из Git `generations/assemblies/`.
